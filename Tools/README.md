# Tools

Notes and practical usage of security tools I've learned, written from hands-on practice in labs and TryHackMe rooms.

## Defensive

| Tool | Used for |
| ---- | -------- |
| [Splunk](./splunk/) | Log search and analysis in a SIEM |
| [Wazuh](./wazuh/) | Open-source SIEM and endpoint monitoring |
| [Snort](./snort/) | Network intrusion detection with rules |
| [Wireshark](./wireshark/) | Packet capture and network traffic analysis |

## Offensive

| Tool | Used for |
| ---- | -------- |
| [Nmap](./nmap/) | Host discovery, port and service scanning |
| [Burp Suite](./burpsuite/) | Intercepting and modifying web requests, testing web apps |
| [Metasploit](./metasploit/) | Exploitation and post-exploitation |
| [Hashcat](./hashcat/) | GPU-based password hash cracking |
| [John the Ripper](./john/) | Password hash cracking and format conversion |
